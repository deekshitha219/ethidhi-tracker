# EtiDhi Company Pipeline Tracker

## Frontend
Put `src/App.jsx`, `src/App.css`, and `src/main.jsx` into your Vite React project.

Run:
npm install
npm run dev

## Backend
From the project folder:
node server/index.js

Backend:
http://localhost:5000

Frontend:
http://localhost:5173

## Important
The CSS belongs in `src/App.css`. Do NOT paste CSS directly into `App.jsx`.

For Render deployment, set the frontend environment variable:
VITE_API_URL=https://YOUR-BACKEND-SERVICE.onrender.com
